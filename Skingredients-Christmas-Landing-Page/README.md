# Skingredients Christmas landing page export

Exported 10 September 2026 from the latest saved source.

This is the editable Sites/React source project with all supplied images used on the page. It is not a standalone HTML file or an installable Shopify theme.

## Contents
- app/page.tsx: page layout, navigation and controls
- app/globals.css: styling, including the 1600px product grid and red savings labels
- app/content.json: editable copy, prices, image references, cart links and video slots
- public/images: optimised product and collection images
- CONTENT-NOTES.md: original copy gaps and handover notes

## Run locally
Use Node.js 22.13 or newer. Open a terminal in this folder, run `npm ci`, then `npm run dev`. Open the local URL printed in the terminal.

Run `npm run build` for a production build.

## Edit content
Change app/content.json, or open the local page with ?edit=1 to use the preview editor. Preview edits last until refresh; Export changes downloads a revised content file. Replace app/content.json with that file to keep the edits in the project.

Renew + Glow is Boots exclusive and has no purchase button. Five grid buttons link to the Skingredients cart using product variant IDs verified on 9 September 2026.

## Hosting
This export omits the original private Sites project ID, credentials, dependencies and Git history. It can be registered as a separate Sites project. The existing hosted preview is unchanged.
