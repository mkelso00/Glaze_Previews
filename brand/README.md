# Brand assets

Drop the Glaze logo here as **`glaze-logo.svg`** (preferred) or **`glaze-logo.png`**.

The preview banner picks it up automatically on the next deploy — no code change
needed. Until a file is present, the banner shows a plain "Glaze" wordmark.

- A wide/horizontal logo works best (it sits ~20px tall in the banner bar).
- SVG or a transparent PNG is ideal so it looks right on the dark banner.
