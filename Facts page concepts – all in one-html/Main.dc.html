How to set this up in Trustmary

  1. Tag every review by flavour, e.g. raspberry, ginger-lemon, live-soda, brew-kit.
  2. One widget, filtered per product. Pass the tag in the embed, set from the product handle in the theme, so each page shows only its own flavour.
  3. Sort newest first and pin one or two strong recent reviews to the top.
  4. Restart collection. Ask for a review 10 to 14 days after delivery, with the flavour already tagged on the request.
  5. Ask a better question: "How did you drink it?" gets specific, useful answers.
  6. Show the date on every review so freshness is visible.
